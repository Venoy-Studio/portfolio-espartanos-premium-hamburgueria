# Portfolio • Espartanos Premium Burgers

Landing page autoral e cardápio digital de alta conversão para a **Espartanos Premium**, hamburgueria artesanal especializada em burgers grelhados na brasa, blends nobres 100% Angus e pão brioche amanteigado. Desenvolvido com Vite, React, TypeScript e Tailwind CSS.

---

## 🚀 Como Executar o Projeto

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
